# Kaven File Copy 0.1.3

Release date: 2026-11-19

## Highlights

- Adds signed automatic update checks at startup and manual update controls under Help.
- Uses `https://public.data.kaven.xyz/json/kaven-file-copy/latest.json` as the canonical update manifest.
- Downloads and verifies signed Windows installer updates before installation.
- Adds the integrated VS Code-style desktop title bar and application menus.
- Adds group selection controls, single-group mode, and optional group confirmation before manual runs.
- Shows per-file copy results when a run finishes.

## Compatibility

- Windows 10 and later remains the release-validated desktop target.
- Existing rules, settings, and job history remain in the stable `Kaven/Data/Kaven-File-Copy` local-data directory.
- Version 0.1.2 did not contain an updater client, so upgrading from 0.1.2 to 0.1.3 requires installing 0.1.3 manually. Later signed releases can be installed through the application.
